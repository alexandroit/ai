# Compatibility

## Repository Development

- Node.js `>=22.13.0`
- pnpm `11.5.2`

## Published Package Runtime

- Node.js `>=18.17.0`
- ESM
- Fetch API primitives for backend packages

## Browser UI

`@stackline/ai-ui` requires:

- Custom Elements
- Shadow DOM
- `fetch`
- `localStorage` for persistence unless disabled

## Vite Examples

Vite 7.3.5 requires Node `^20.19.0 || >=22.12.0`.
